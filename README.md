# LR1 — Абстрактные структуры данных

Проект написан на C++17.

## Файлы
- `main.cpp` — интерфейс команд, короткие псевдонимы, чтение/запись истории команд.
- `ds.h` — объявления классов и узлов.
- `ds.cpp` — реализации массива, односвязного и двусвязного списков, стека, очереди и Complete Binary Tree.

## Сборка
```bash
g++ -std=c++17 main.cpp ds.cpp -o main
```

## Интерактивный запуск
```bash
./main --file file.data
```
Внутри программы команда `help` показывает примеры, `exit` завершает работу.

## Примеры коротких команд
```text
ap 10       # добавить 10 в массив
av          # вывести массив
fp 10       # добавить 10 в хвост односвязного списка
sp 10       # положить 10 в стек
so          # извлечь верхний элемент стека
qp 10       # добавить 10 в очередь
qo          # извлечь голову очереди
ti 10       # добавить 10 в Complete Binary Tree
ts 10       # поиск 10 в дереве
tc          # проверить полноту дерева
tv          # вывести дерево по уровням
```

Файл данных содержит историю успешно выполненных команд, меняющих структуру. При запуске программа повторно исполняет эту историю для восстановления содержимого контейнеров.
